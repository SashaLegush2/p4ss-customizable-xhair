# Customizable Passtime JACK Crosshair

this was originally, supposed to be an addon for PASS Fortress HUD, but because i thought it was pretty cool (and because its either impossible, or insanely hard to set up to work as a .vpk) i decided to make it a fully seperate project of mine.

How to use?

Because this was made for PFHUD, i didnt intend for it to be used anywhere else, however you can! I'm trying to make a small webtool that lets you choose different crosshair images to make a crosshair of your own, with ASTONISHING 150 colors to choose from!!!!!!
